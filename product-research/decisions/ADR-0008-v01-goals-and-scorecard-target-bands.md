# ADR-0008 v0.1 Goals And Scorecard Target Bands

## Status
- Accepted

## Goal To Metric Mapping
- Task continuity success rate
- Rework reduction
- Trusted autonomy rate
- Memory precision
- Memory error rate
- Cost predictability
- Trace completeness
- Weekly active memory-enabled workflows
- Multi-session workflow completion rate

## Target Bands
- Green: target operating band for v0.1 release checkpoints.
- Yellow: watch band requiring focused remediation.
- Red: miss band requiring corrective action before ship.

## Notes
- This ADR defines scorecard semantics used by KPI snapshots and release decisions.
